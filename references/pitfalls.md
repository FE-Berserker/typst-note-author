# 踩坑记录

按「症状 → 原因 → 修法」组织。改样板出问题时先来这里找，
多数是实际翻过车的点。相关背景见 `design.md`。

## 旁注

**同一页几条旁注全叠在一处**

`place` 写在段落里时，定位基准是**外层容器**而不是当前这一行：
`place(left + horizon, …)` 会落在整页版心的垂直中心，
`place(left + top, …)` 落在版心顶部，都与所在行无关。
把内容从块级的 `block` 换成行内的 `box` 也一样；外面再包一层 `context`
（想顺便 measure 出行高）会让基准进一步降级成「所在块的垂直中心」。

行级锚定的旁注在 Typst 里做不出来。本模板改用 `grid` 把正文与旁注并排，
旁注顶边对齐段落顶边。详见 `design.md` 的「旁注」一节。

**旁注与正文对不齐（差半行、差几行）**

旁注锚在**段落**顶边，不锚在句子上。要对准某个句子，把段落拆短；
一条旁注配一个段落，同段想要两条就把段落拆成两段。

**正文里凭空多出一段空白**

一行的高度取正文与旁注的较大者。旁注比正文长时，正文那一侧就余出空白。
把旁注写短（三五行为宜），或者把 `note-note-width` 调宽一点让旁注少折几行。

**`#pnote` 里的段落丢了首行缩进**

Typst 不给网格单元格内的第一个段落加首行缩进，在单元格里写
`set par(first-line-indent: …)` 也不生效（两种写法都实测过）。
模板用 `note-par` 显式包一层解决：

```typst
#let note-par(body) = par(first-line-indent: (amount: note-par-indent, all: true))[#body]
```

自己写新的网格类版式时记得同一件事。另外 `par` 的 `body` 是位置参数，
`par(body: …)` 会被拒（"the argument `body` is positional"），
`par(…, body)` 会落到 `leading` 上——只能用尾随内容块的形式传。

### mnote 专属的几条

**`document did not converge within five attempts`**

`mnote` 靠 state 记录每条旁注的落点来互相避让，每来一条就多一轮排版。
整篇笔记每条注解都用 `mnote` 时轮次会叠上去，极端文档上报这个错。

修法：把离得最近的几条 `mnote` 改回 `pnote`（它不参与 state 循环），
或者把相邻几条旁注合成一条。一般改一两条就够。
相关背景见 `design.md` 的「行级旁注」小节。

**长旁注压到了 `#wide` 通栏块上**

marginalia 只避让**它自己**的 `wideblock`（内部写进 `_note_extends_right`
等私有 state），与模板的 `wide` 互不知情。通栏块借走了旁注栏那一列，
落点靠近它的 `mnote` 不会让开。实测：旁注底部与通栏块的纵向范围重叠时，
文字会压在块上。

修法：那条旁注加 `dy` 手工挪开（`#mnote(dy: -8pt)[…]`），或者改用
`pnote` 写在该段落上。别去动 `wideblock` 的私有 state——不是公开 API。

**`mnote` 传了 `side: "left"` 被断言拦下**

模板左边距只有 2.0cm，放不下注解，所以 `mnote` 只排右侧。这是有意的：
错误信息里会把左边距的实际值印出来。要左右都有旁注栏，先把
`note-margin-left` 调宽到能容纳 `note-note-width`，再把 `mnote` 里的断言
一并放宽。

**旁注编号印出来是符号不是数字**

`mnote(counter: marginalia.notecounter)` 用的是 marginalia 自己的锚点符号
（● ○ ◆ …），不是阿拉伯数字。这是它的设计（避免和页码、图表编号抢），
`@mn:x` 引用印出的也是同一枚符号。想要数字编号目前只能自己传 `counter:`。

## 交叉引用

**正文里出现「图 图 1」「表 表 2」**

`@fig:x` 与 `@tab:x` 渲染出来是**自带标签**的：「图 1」「表 2」。
所以紧挨着引用手写「图」「表」就会重复一次：

```typst
见图 @fig:x 的布局      // ✗ 渲染成「见图 图 3 的布局」
见 @fig:x 的布局        // ✓ 渲染成「见图 3 的布局」
表 @tab:x 汇总了        // ✗ 渲染成「表 表 2 汇总了」
@tab:x 汇总了           // ✓ 渲染成「表 2 汇总了」
```

这个错误很容易漏掉——源码读起来完全通顺，只有编译出来才看得见。
从别处搬内容进来时，全文搜一遍 `图 @fig:` 与 `表 @tab:` 就能一次性揪出来。

**`@sec:x` 引用报 cannot reference heading without numbering**

笔记的节标题默认不编号，而 Typst 不允许引用无编号的标题。
模板用一条 `show ref` 规则接管成印标题文字；想换成编号式引用
（「见 2.2 节」），见 customization.md 的「交叉引用印编号还是印标题」。

**跨篇引用在单篇导出时报 label does not exist**

汇总册里 Typst 的标签全文可见，`@sec:…` 能直接引用另一篇里的节（印出来
是那节的标题文字）；单篇导出只 include 当前这一篇，引用别的笔记的标签会
直接编译报错。要在单篇里指向别的笔记，用 `#link("另一篇.pdf")[…]`。

## 笔记头与目录

**标签渲染成一串单字**

`tags` 写成了字符串：`tags: "Typst"`。`.len()` 对字符串照样返回长度、
`for` 逐字符渲染，全程不报错，只是标签变成一串单字。`tags` 必须是数组：
`tags: ("Typst", "模板")`——模板在编译期就会 assert，看到报错按提示改即可。

**汇总册目录里出现了正文的小节，或者目录是空的**

正文里写了一级标题（`= …`）。一级标题的位置属于笔记头——`note-header`
埋了一枚**隐形的一级标题**供目录使用。正文一律从 `==` 起。

**目录里笔记标题的顺序不对**

顺序由 `collection.typ` 里 `#include` 的先后决定，与文件名无关。

**笔记没有标题、定理编号接着上一篇数**

漏了 `#note-header(…)`。它除了画版面，还负责新建一页、埋隐形标题、
把定理编号归零——只写正文会得到一篇「无头」笔记。

**单篇与汇总册里图表编号不一样**

`图 1`、`表 1` 是全文连续的：单篇导出时从 1 开始，汇总册里接着上一篇往下数。
这是 Typst 的 `figure` 计数行为，模板没有干预。跨版本引用编号时要留意。

**往中间插一篇，后面各篇的主题色整体后移一位**

篇序决定颜色，与文件名无关。在意某一篇的颜色就在它的 `note-header` 里写
`theme: note-themes.xxx`，写死之后不受影响。

**`theme:` 传了字符串，编译期 assert**

`theme: note-themes.indigo` 是颜色，`theme: "indigo"` 不是——色板是按名字
查字典取出来的，字典的键不是字符串。报错信息会照实说拿到了什么。

**黑白打印稿里分不出前后篇的主题色**

六种主题色换算成灰之后，红与靛、赭与青只差一档亮度，基本分不出。
黑白稿认标题，别认颜色。

**提醒框在青色主题的笔记里还是橙色**

这是有意的：主题色只管四处（笔记头短标、节标题竖标、摘要竖线、旁注竖线），
提示框、数据系列、状态点是语义色，不跟着主题色走。想让它们变色就改错了地方——
语义色一旦身兼多职就不叫语义色了。

**想把「挑过哪些色」记下来，编译报 did not converge**

在 `context { … }` 里 `state.update()` 一个**依赖自己旧值**的 state（比如
「已用色」列表），Typst 每轮排版会把整个 context 块重新应用一次，列表越攒越长，
十轮之后还不收敛。模板因此改用 `counter("note-theme-index")`：计数器写在普通
代码里，每轮只走一次，天然收敛。自己加新的跨模块状态时也照这个来。

## 表格

**表格是一张满格的网，不是三线表**

三线表靠 `note-setup` 里的 `set table(stroke: …)` 与一条 `show table` 规则
实现。自己新建的表格若显式传了 `stroke:`，会覆盖掉这套默认，回到满格。
去掉自己的 `stroke:` 即可。

**表格底线比表格本身长出一截**

补底线的那层 `block` 写了 `width: 100%`。去掉宽度，让它随表格收缩。

**想给某行单独加线**

`table.hline(stroke: …)` 直接写在该行后面。注意 `set table(stroke:)` 的
函数形式只收到整数坐标，`"first"` / `"last"` 实测收不到，所以按行号判断时
只能写死数字。

**加了列间距后三线表多出竖线**

Typst 会把 `table` 的 `stroke` 画进 `column-gutter`。用单元格内边距
（`table.cell(inset: …)`）留气口，别用 gutter。模板已经这么设了。

## 字体与中文

**正文整体特粗**

字体链里放了只装单一粗字重的字体族（如仅 Heavy 的思源宋体），找不到常规
字重就退到粗字重。链里只放完整字重族的字体。

**代码块或公式里的中文变成隶书等奇怪字体**

`raw` 与 `math.equation` 的字体是纯西文的，Typst 会在系统字体里随机挑中文。
模板已显式补了中文字体回退；自己改字体时别把中文字体从这两条链里删掉。

**强调没有效果（还是正体）**

汉字没有斜体字形，套斜体只得正体。中文强调用楷体（`note-font-kai`）。
加粗同理不要用换黑体冒充（那是换字体，删字重后失效）。

**图注标签是英文 Figure**

模板设了 `lang: "zh"`，Typst 会自己本地化「图 / 表」。若哪里的标签仍是英文，
检查是不是某处 `set text(lang: …)` 把它改回了非中文。
不要用字符串替换 `#show "Figure": [图]`——会误伤代码块与英文引文。

## 页面与编译

**单页笔记没有页码**

这是有意的：总页数为 1 时不印页码。多于一页就会出现。

**续页的书眉空着**

书眉只在本页**不是**某篇笔记的第一页时出现。若一篇笔记只有一页，
它自然没有书眉——不是漏印。

**首次编译拉取依赖失败 / 随机字形**

`@preview` 包（showybox、heroic、cetz、fletcher、lilaq、tiptoe、marginalia）需联网；
系统缺 Noto Serif SC / SimHei 等字体时 Typst 会乱挑替代。
先确认 `typst compile` 联网跑通一次，再查字体。

**warning: document did not converge within five attempts**

某处版面在多轮排版之间来回摆动。本模板的常见来源有两个：把内容很长的提示框
放在页尾（框默认不跨页）；以及整篇密集使用 `#mnote`（每条都参与一轮 state
循环）。输出 PDF 一般不受影响；要消除告警，微调该处内容、挪动小节位置，
或把几条 `mnote` 改回 `pnote`。
